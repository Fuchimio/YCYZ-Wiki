# 银川一中校园指南

**养正人的校园指南针。**

一个面向银川一中学生的校园综合信息门户与 Wiki 知识库，致力于整理校园信息、记录校园生活、分享实用指南，让每一位养正人都能更轻松地了解校园、融入校园。

## 项目简介

银川一中校园指南（YCYZ Wiki）是一个由学生、校友参与建设的校园信息平台。

项目以 Wiki 知识库为基础，逐步整合校园资讯、通知公告、校园生活指南等内容，为在校学生提供一个统一、便捷、易于维护的校园信息入口。

我们希望它不仅是一本校园说明书，也能成为记录校园文化、分享校园经验的地方。

## 项目目标

- **信息整合**：集中整理校园相关信息，减少信息获取成本。
- **知识共享**：通过 Wiki 的形式沉淀校园知识与实用经验。
- **校园记录**：记录校园活动、校园生活与值得留存的内容。
- **持续建设**：建立易于维护、方便参与和长期更新的内容平台。

## 技术栈

| 技术 | 用途 |
|---|---|
| [VitePress](https://vitepress.dev/) | 静态站点生成与 Markdown 内容管理 |
| [Vue 3](https://vuejs.org/) | 自定义主题与交互组件 |
| [TypeScript](https://www.typescriptlang.org/) | 类型安全 |
| [Vite](https://vite.dev/) | 开发与构建工具 |
| [pnpm](https://pnpm.io/) | 包管理工具 |

项目采用 VitePress + Vue 3 的技术架构，基于 Markdown 管理内容，并通过自定义主题构建校园门户与 Wiki 阅读体验。

## 本地开发

### 环境要求

- Node.js
- pnpm

### 克隆仓库

```bash
git clone https://github.com/Fuchimio/YCYZ-Wiki.git
cd YCYZ-Wiki
```

### 安装依赖

```bash
pnpm install
```

### 启动开发服务器

```bash
pnpm run docs:dev
```

启动后访问：

```text
http://localhost:5173/
```

### 构建生产版本

```bash
pnpm run docs:build
```

### 本地预览

```bash
pnpm run docs:preview
```

## 内容建设

项目主要使用 Markdown 编写内容。

我们希望内容具有以下特点：

- 准确、实用，尽可能提供可靠的信息来源。
- 结构清晰，方便阅读和检索。
- 及时更新，避免过时信息误导读者。
- 尊重事实，区分官方信息、经验分享与个人观点。
- 保护个人隐私，不公开未经允许的个人信息。

## 参与贡献

欢迎对校园指南提出建议、反馈问题，或参与内容建设。

你可以通过以下方式参与：

1. 提交 Issue，反馈错误、提出建议。
2. 提交 Pull Request，完善内容或改进代码。
3. 分享校园经验，帮助补充 Wiki 知识。

参与内容建设时，请尽量保证信息真实、准确，并注明必要的信息来源。

## 项目声明

本项目是面向校园学生建设的信息整理与知识共享平台。

网站内容不应被视为学校正式发布的通知或公告。涉及学校政策、规章制度及重要事项时，请以学校官方发布的信息为准。
